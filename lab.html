Proctor lab

Run a recording through the detector, mark what actually happened, and see what it got right. Same code that watches a live game — measured instead of trusted.

/ WHY THIS EXISTS

A detector nobody has scored is a guess. Record one game with OBS, drop the file in, and this replays it frame by frame — deterministic, repeatable, and honest about what it missed.

/ THE FILE STAYS HERE

The video is read by this page and never uploaded. Nothing on this page talks to the server at all.

/ SELF TEST

Synthetic frames, no footage needed: idle noise, an overlay that opens, one card that animates, the overlay closing. Proves the state machine fires in the right order and names the right third. It cannot prove anything about real TFT — that is what the replay below is for.

/ WHAT ACTUALLY HAPPENED

/ CALIBRATE A MATCHER

Each restriction the proctor can watch is one picture of one thing in one place. Scrub the recording to the moment — a carousel round, the gold counter reading zero, a board with no trait active — pick the matcher, check the box lands on it, and capture. It is saved for this browser straight away; the string below goes into lib/matchers.js to ship it to everyone.
